# Problem Characteristic Analyzer

## Purpose

This module studies how the existing rule-based scheduling baselines perform
under different scheduling problem characteristics. It is an evidence-gathering
stage for the thesis titled:

**A Problem-Characteristic-Aware Adaptive Multi-Agent AI Framework for Task Scheduling**

It does not yet implement the adaptive multi-agent policy and does not infer
causation from correlations.

## Input

Use the `results.json` generated by the baseline benchmarking engine. It must
contain per-instance records for FCFS, SPT and Critical Path, including numeric
characteristics and metrics.

## Run

From the repository root:

```powershell
py -m src.analysis.problem_characteristic_analyzer --input baseline_results/results.json --output characteristic_analysis
```

To use five equal-frequency bins instead of three:

```powershell
py -m src.analysis.problem_characteristic_analyzer --input baseline_results/results.json --output characteristic_analysis --bins 5
```

## Method

For each characteristic, the analyzer:
1. Reads one characteristic value per unique instance and checks consistency
   across that instance's algorithm records.
2. Sorts the unique values and assigns equal-frequency rank bins. Equal values
   are never split across bins. With three bins, labels are low, medium and high.
3. Calculates per-algorithm mean, median and standard deviation for each metric
   in each bin.
4. Selects the best mean-performing algorithm per bin and metric according to
   the metric direction (minimize or maximize). Ties are retained.
5. Calculates exploratory Spearman rank correlations between each characteristic
   and each metric for each algorithm.

The analyzer uses only successful runs for metric statistics, but counts failed
runs and reports success rates. It does not discard failed runs silently.

## Output files

- `characteristic_analysis.json`: complete analysis and metadata.
- `performance_by_characteristic.csv`: algorithm metrics by characteristic bin.
- `best_algorithm_by_characteristic.csv`: descriptive per-bin winners per metric.
- `characteristic_metric_associations.csv`: Spearman rank correlations.

## Interpretation cautions

- Per-bin winners are descriptive comparisons of means, not statistical
  significance tests.
- Spearman correlations describe monotonic association, not causality.
- Equal-frequency bins are relative to the analyzed dataset; their numeric
  ranges may change when the dataset changes.
- Resource cost may be identical across algorithms under the current evaluator,
  because the current cost model depends on task duration, resource demand and
  resource rate rather than start time.
- Use multiple seeds and held-out instances before turning these exploratory
  observations into an adaptive coordination rule.
